# Changelog

## Unreleased

### Added
- Gallery of cursor sets grouped by source, with search and an "In use" badge.
- Set detail view with animated previews of all 17 pointers; apply one pointer or the whole set.
- Applying a set registers it as a Windows scheme (`PointerParlor - <set>`).
- Import from `.inf` install packages, folders, `.zip` files, and loose `.cur`/`.ani` files, with a review step to fix pointer assignments. Drag and drop onto the gallery works too.
- Save the current mix of pointers as a set under My sets.
- Undo the last change; reset to the Windows default cursors.
- Pointer size slider (same setting as Windows), with a warning when a set's images are smaller than the chosen size.
- Light, dark, or Windows theme.
